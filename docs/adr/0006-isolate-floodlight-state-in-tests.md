# ADR-0006. Перезапускать Floodlight между топологиями в тестах

- **Статус:** Accepted
- **Дата:** 2026-10-08
- **Спецификации:** `openspec/specs/sdn-lab-environment` (требование
  «Изоляция состояния контроллера между топологиями»),
  `openspec/specs/lab4-mininet-topologies`
- **Процесс:** [P8](./processes.md#p8-жизненный-цикл-floodlight-в-тестах)

## Контекст

Integration-тесты последовательно поднимают 5 топологий на одном экземпляре
Floodlight. Коммутаторы разных топологий имеют одинаковые DPID (`s1..s4` →
`0x1..0x4`) и переподключаются за секунды. Floodlight 1.2 хранит связи без
LLDP ещё до 35 с и строит маршруты по устаревшему графу. Результат –
асимметричная недоступность (`h1 -> X X X`, при этом `h3 -> h1` работает),
50–100% потерь, зависание `iperf`. Проверка «связей не меньше ожидаемого»
этого не замечала: старые связи совпадали по количеству.

## Решение

- Session-фикстура `floodlight` запускает контроллер сама, если порт 6653
  свободен, и останавливает его в конце сессии.
- Перед каждой топологией фикстура `floodlight_net` вызывает
  `Floodlight.reset()` (stop + start, около 3 с) – только для своего
  процесса. Внешний Floodlight не перезапускается.
- Одна сеть на топологию (`scope="module"`): 5 смен топологии вместо 15.
- Готовность сети – **точное** совпадение множества связей из REST с
  топологией (таймаут 90 с), а не сравнение количества.

### Рассмотренные альтернативы

- **Ждать истечения устаревших связей (≥ 35 с) на каждую смену.** Медленнее
  и не устраняет устаревшие устройства. Отклонено.
- **Уникальные DPID во всех тестовых топологиях.** Расходится с поведением
  скриптов, которые запускает пользователь. Отклонено.

## Последствия

- `make test`: 108 passed примерно за 2.5 мин, повторяемо.
- С внешним, долго работающим Floodlight такие сбои возможны. Это
  задокументировано в README: для чистого прогона внешний контроллер нужно
  остановить.
- Тест, который запускал `TreeTopo.py` целиком под Floodlight, удалён: после
  перезапуска контроллера он зависал на `pingAll` без таймаута. Сеть tree
  покрыта фикстурой `floodlight_net`.
